## 1. Android — 상세 검증 (build3, 실기기급 에뮬레이터)

### 실행 환경
- **에뮬레이터 3대 동시 실행** — 5554(원장)·5556(교사)·5558(학생), 각 build3 설치 + 계정 로그인.
- 계정: director@test.com / teacher@test.com / student@test.com (전부 테스트 계정).

### 역할별 기능 (모두 렌더 + 무크래시)
| 역할 | 검증 화면 | 결과 |
|---|---|---|
| **학생** | 홈(공지·연습시간·루틴)·연습·배움(퀴즈·읽을거리·**AI 첨삭**·**모의테스트**)·MY(갈채·교환소)·내 정보(**계정 삭제** 신규) | ✅ 정상 |
| **원장** | 현황 대시보드(학생 31명·클래스별)·일정·**모의테스트 관리** | ✅ 정상 |
| **교사** | 피드백 인박스(학생 영상 리뷰·제출 대기) | ✅ 정상 |

### 신규 기능 심층 E2E — **모의테스트 전체 CRUD (백엔드 DB 검증 포함)**
1. **생성 폼**: usersApi로 실제 학생 목록 로드 + role 필터 정상.
2. **학생 선택**: 탭 순서 = 순번(배지 "1" 표시) 정상.
3. **생성**: `만들기` → POST /api/mock-tests → DB에 MockTest + Entry 생성 확인(순번 sort_order=0). "완료" 알림.
4. **목록**: 생성분이 "학생 1명 · 음원 0/1"로 즉시 표시.
5. **상세**: 참여 학생 순번순 + 상태(대기) + 영상 올리기·공지·삭제 버튼.
6. **삭제**: DELETE → DB에서 MockTest·Entry cascade 삭제 확인(0건).

### AI 면접 첨삭
- 화면(질문·답변 입력·첨삭받기) **렌더 확인**. **실제 제출은 비용 때문에 미실행**(지시 준수). 백엔드 OpenAI 동작은 이전 세션에서 별도 검증됨.

### ⭐ 실시간 동시성 (WebSocket) — 핵심 검증
- **원장(5554)이 모의테스트 생성 + 공지 발송** → **학생(5558) 앱을 전혀 건드리지 않았는데** 학생 홈의 "학원 공지" 최상단에 **"[모의테스트] RT_TEST"가 라이브로 나타남** + 알림 배지 증가.
- 백엔드 확인: 테스트 학생에게 "모의테스트 공지: RT_TEST" 알림 + Notice 생성됨.
- → **3역할 동시 접속 + 크로스롤 실시간 데이터 반영(useDataRefresh/WebSocket) 정상 작동.**

### 최적화 (R8) 런타임
- dex 27MB → **10.4MB(−61%)**, 앱 정상 실행 + 신규 화면 렌더 + 크래시 0 → R8 keep 규칙 문제 없음.

## 2. iOS — 딥 인터랙션 검증 (Release 시뮬레이터 빌드, idb 자동조작)

### 실행 환경
- **빌드 성공**(expo run:ios --configuration Release, iPhone 17 Pro 시뮬레이터, New Architecture).
- **fb-idb 설치**(이전 세션의 "도구 없음" 한계 해소) → 실제 텍스트 입력·탭·스와이프·접근성 트리 조회로 **손으로 쓰듯 조작**. 한 대씩(원장 → 로그아웃 → 학생) 순차 검증.

### 역할별 딥 인터랙션 (실제 조작 + 화면 캡처 확인)
| 역할 | 실제 수행한 조작 | 결과 |
|---|---|---|
| **원장** | 로그인(director@test.com) → 현황 대시보드(**실데이터**: 학생 수·클래스별) → 일정 탭 → **🎤 모의테스트 관리 카드 진입** | ✅ 정상 렌더·이동 |
| **학생** | 내정보 화면서 **로그아웃**(확인 다이얼로그) → 로그인(student@test.com) → 홈(**실데이터**: 학원 공지 3건·오늘의 루틴·이번달 연습) → **배움 탭**(상식퀴즈·읽을거리·질의응답) → **✨AI 첨삭 버튼 노출 확인** → **모의테스트 참여 화면 진입**(백엔드 조회 후 빈 상태 정상 렌더) | ✅ 정상 |

- **신규 기능 iOS 노출 확인**: 배움 탭의 **✨AI 첨삭** 버튼 + **모의테스트 참여** 카드 둘 다 렌더, 모의테스트 화면은 `mockTestApi.mine` 호출 후 "참여 중인 모의테스트가 없어요" 빈 상태 정상(테스트 데이터 정리 상태 반영).
- **네이티브 모듈(expo-video·expo-audio·expo-document-picker·native-upload) 크래시 없이 로드** — 화면 진입 시 크래시 0.
- **iOS Keychain 지속성 확인**: 앱 재설치로는 세션이 안 지워짐(expo-secure-store=Keychain) → 반드시 앱 UI 로그아웃으로 계정 전환해야 함(운영 팁).
- **AI 첨삭 실제 제출은 미실행**(비용 지시 준수) — 버튼 렌더까지만.

## 3. 미검증/제외 항목 (정직 고지)
- **AI 첨삭 실제 제출**: 사용자 지시(비용)로 제외 — 화면 렌더만.
- **학생 모의테스트 음원 업로드(document-picker)**: 파일 선택 UI가 수동 상호작용 필요 — 화면·백엔드 경로는 검증, 실제 파일 업로드는 수동 권장.
- **iOS 교사 역할 딥 인터랙션**: 원장·학생 2역할만 iOS서 직접 조작(교사는 Android서 상세 검증 완료, JS 100% 공용이라 동일 기대). iOS 3역할 동시·실시간 왕복은 미수행(단일 시뮬레이터 순차 검증).
- **원장 스토어 빌드(iOS)**: Apple 로그인 필요(사용자만 가능) — 이 테스트는 시뮬레이터 개발빌드로 수행.
